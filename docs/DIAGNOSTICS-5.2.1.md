# 5.2.1 점검 개선 — 2026-09-21

사용자가 제공한 77종목 점검 결과와 로컬 코드의 대조 결과입니다. 첨부 시점은 재무조회 16/77로 갱신 중이었습니다.

## 수정

- 고정된 v4.38 빌드명 → v5.2.1. 판단 규칙은 v5.2 유지.
- JSON 복사 때 최신 상태 재수집, 비동기 클립보드 오류 처리, JSON 다운로드 추가.
- 로그의 읽기 상태·대기 사유·저장 시도·오류 코드 노출. 기록 없음의 원인을 수집 전이라고 단정하지 않음.
- PSR 괴리 비율과 내포가를 같은 산식으로 표시. 환산 후 직접 계산값과 기존 대체 표시값을 분리.
- PSR 비교의 동일 주당·통화 기준 가정을 명시. 괴리만으로 ADR 또는 가격 변동이 원인이라고 단정하던 설명 제거.
- 종목별 수집시각과 수동/자동 PSR 입력을 JSON에 포함.
- CapEx 0은 미수신으로 표시. 기업의 투자액 0이나 데이터 정상의 증거로 해석하지 않음.

## 추가 확인이 필요한 사항

1. 로그 미저장: 조회 완료 후 새 JSON의 로그상태에서 대기와 저장/조회 실패를 구분합니다. 실제 Firebase 오류는 아직 재현하지 않았습니다.
2. ASML·TSM·QNT 등의 PSR: 원천 응답과 ADR/분할/통화/기준기간 확인 전에는 어느 필드가 틀렸는지 확정할 수 없습니다. 기존 PSR·PBR 대체값의 환율 나눗셈도 원천 단위 확인이 필요합니다.
3. SPCX의 큰 괴리: 주당매출이 기존 극단값 배제 기준 안에 있어도 정합성이 입증된 것은 아닙니다. 원천을 확인해야 합니다.
4. QNT·SPCX의 짧은 이력과 국내 ETF의 빈 펀드 응답은 각각 관측 부족과 자료 미수신으로 구분합니다. 종목별 원인은 응답 확인 전 미확정입니다.

이 변경은 점검·관측 기능을 고칩니다. 평가 임계값이나 기존 투자 판단 산식은 변경하지 않습니다. 원격 배포는 수행하지 않았습니다.

## 검증 결과

오프라인 검사 88개 통과. 합성 데이터로 Edge 1440·390·320px에서 점검 화면, JSON 다운로드, 페이지 가로 넘침 및 실행 오류 여부를 확인했습니다. 실제 운영 계정의 오류 원인은 아직 확인하지 않았습니다.
